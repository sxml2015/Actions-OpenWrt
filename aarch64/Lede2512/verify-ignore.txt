# ============================================================================
#  verify-ignore.txt —— 插件清单校验白名单
#
#  作用：
#    make defconfig 之后，gen_config.py --verify-strict 会逐个检查
#    plugins.cfg 里标 on 的插件，最终 .config 里是否真的 =y。
#    只要有一个没启用，编译立刻中止（10 秒内），不会白编 4 小时。
#
#  什么时候往这里加：
#    某个插件「标了 on、但客观上不可能启用」，且确认这是正常的。
#    典型情况：
#      · 该包只在特定平台/架构下才存在（我们的 armsr/armv8 上没有）
#      · 该包被上游拆包改名，旧名字已不存在，但清单暂时保留
#      · 该包依赖某个不打算编的组件，Kconfig 因此隐藏了它
#
#  什么时候不要往这里加：
#    · 你真想要这个插件 —— 那是配置写错了，去查包名或 thirdparty.cfg
#    · 你不确定要不要它 —— 那就在 plugins.cfg 里改成 off，比加白名单清楚
#
#  写法：
#    每行一个，'#' 之后为注释。包名写 luci-app-xxx 或写完整
#    CONFIG_PACKAGE_luci-app-xxx 都可以，两种等价。
#
#  注意：
#    不要为了让编译「过」而把真需要的插件塞进来 —— 那等于关掉了这道防线。
# ============================================================================

# --- A. turboacc 全家（6 项）------------------------------------------------
